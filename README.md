# 猫女桌面宠物

一款安卓桌面悬浮宠物，通过无障碍服务在本地监测手机前台使用时长，猫女会根据你设定的每日目标自动切换表情（开心 / 平静 / 困倦 / 生气），帮你看清每天刷手机花了多少时间。

## 版本

- v1.0.0（正式签名版）`catgirl-pet-release-signed.apk`

## 安装

1. 下载上面的 APK 并安装。
2. 打开 App，授予「无障碍」服务权限。
3. 设置每日目标使用时长，启动宠物即可。

> 说明：统计只在本地进行，不上传任何数据。因 ROM 限制，推荐使用无障碍方案（已内置适配华为等封闭系统）。

完整图文安装说明见 `catgirl_pet_share_guide.html`。
