# 猫女桌面宠物

一只会根据手机使用时间变换表情的悬浮桌宠小猫娘。

## 最新版下载 (v1.1.0)

直接下载 APK：
`https://github.com/cb9991/-catgirl-pet/releases/download/v1.1.0/catgirl-pet-release-signed-v1.1.0.apk`

## 功能
- 无障碍本地统计今日使用时长（不分具体 App）
- 自定义今日目标时长
- 猫娘表情随使用时长变化：开心→平静→困倦→生气
- 重置今日时间（清零重新计时）
- 数据仅存本机，不上传

详见 `catgirl_pet_share_guide.html` 或仓库 Release。
